┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 1: Install Fly CLI                                                     │
└──────────────────────────────────────────────────────────────────────────────┘

Windows:
  powershell -Command "iwr https://fly.io/install.ps1 -useb | iex"

Mac:
  brew install flyctl

Linux:
  curl -L https://fly.io/install.sh | sh


┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 2: Sign Up & Login                                                     │
└──────────────────────────────────────────────────────────────────────────────┘

  flyctl auth signup    # Create account + add card (required but won't charge)
  flyctl auth login     # Login


┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 3: Create PostgreSQL Database                                          │
└──────────────────────────────────────────────────────────────────────────────┘

  flyctl postgres create

  Answer prompts:
    App name: medvision-db
    Region: San Jose (sjc)
    Configuration: Development (256MB, 1GB disk)

  ⚠️ SAVE THE PASSWORD SHOWN!


┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 4: Deploy Backend                                                      │
└──────────────────────────────────────────────────────────────────────────────┐

cd c:\Users\bc833\Downloads\diabetic-ulcer-ai-system

# Initialize app (don't deploy yet)
flyctl launch --no-deploy
  App name: medvision-ai-backend
  Region: San Jose (sjc)
  PostgreSQL: No (already created)
  Redis: No

# Attach database (sets DATABASE_URL automatically)
flyctl postgres attach medvision-db --app medvision-ai-backend

# Set Firebase credentials
flyctl secrets set FIREBASE_PROJECT_ID="dfuai-1f1af" --app medvision-ai-backend

# Copy single-line JSON from FIREBASE_RENDER_CONFIG.txt, then:
flyctl secrets set 'FIREBASE_SERVICE_ACCOUNT_JSON={"type":"service_account"...}' --app medvision-ai-backend

# Set frontend URL (update after Vercel deploy)
flyctl secrets set FRONTEND_URL="https://your-app.vercel.app" --app medvision-ai-backend

# Set CORS
flyctl secrets set ALLOWED_ORIGINS="https://your-app.vercel.app,http://localhost:5173" --app medvision-ai-backend

# Set secret key (Windows - use any 32-char random string)
flyctl secrets set SECRET_KEY="your-random-32-character-string" --app medvision-ai-backend

# Deploy!
flyctl deploy --app medvision-ai-backend


┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 5: Verify                                                               │
└──────────────────────────────────────────────────────────────────────────────┘

# Check status
flyctl status --app medvision-ai-backend

# View logs
flyctl logs --app medvision-ai-backend

# Open in browser
flyctl open --app medvision-ai-backend

# Test health endpoint
curl https://medvision-ai-backend.fly.dev/health

╚══════════════════════════════════════════════════════════════════════════════╝

╔══════════════════════════════════════════════════════════════════════════════╗
║                           TROUBLESHOOTING                                    ║
╚══════════════════════════════════════════════════════════════════════════════╝

❌ Build failed?
   → Check logs: flyctl logs --app medvision-ai-backend
   → Ensure you're in project root directory

❌ Health check failing?
   → Increase grace_period in fly.toml to 120s
   → Redeploy: flyctl deploy

❌ Database connection failed?
   → Re-attach: flyctl postgres attach medvision-db --app medvision-ai-backend

❌ Firebase auth not working?
   → Verify secrets: flyctl secrets list --app medvision-ai-backend
   → Re-set if missing (see STEP 4 above)

❌ CORS errors?
   → Update ALLOWED_ORIGINS with your Vercel URL
