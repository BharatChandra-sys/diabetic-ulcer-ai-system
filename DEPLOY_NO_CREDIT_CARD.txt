┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 1: Neon PostgreSQL (2 min)                                             │
└──────────────────────────────────────────────────────────────────────────────┘

1. Go to: https://neon.tech
2. Sign up with GitHub/Google (NO credit card)
3. Create project: "medvision-db"
4. Copy connection string:
   postgresql://user:pass@ep-xxx.us-east-1.aws.neon.tech/neondb?sslmode=require

SAVE THIS! You'll need it in Step 2.


┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 2: PythonAnywhere Backend (15 min)                                     │
└──────────────────────────────────────────────────────────────────────────────┘

1. Go to: https://www.pythonanywhere.com
2. Create free account
3. Choose username (becomes: username.pythonanywhere.com)

4. In Bash console:
   git clone https://github.com/BharatChandra-sys/diabetic-ulcer-ai-system.git
   cd diabetic-ulcer-ai-system
   python3.11 -m venv venv
   source venv/bin/activate
   pip install -r backend/requirements.txt

5. Create WSGI file: /var/www/username_pythonanywhere_com_wsgi.py
   (See PYTHONANYWHERE_DEPLOY.md for full content)

6. Web tab → Add new web app → Manual config → Python 3.11

7. Set paths:
   - Source code: /home/username/diabetic-ulcer-ai-system
   - Virtualenv: /home/username/diabetic-ulcer-ai-system/venv

8. Click "Reload"

Your backend: https://username.pythonanywhere.com


┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 3: Vercel Frontend (5 min)                                             │
└──────────────────────────────────────────────────────────────────────────────┘

1. Update frontend/.env.production:
   VITE_API_BASE_URL=https://username.pythonanywhere.com

2. Deploy:
   cd frontend
   vercel login
   vercel --prod

3. Get your Vercel URL: https://medvision-ai.vercel.app

4. Update PythonAnywhere WSGI with Vercel URL

5. Reload PythonAnywhere web app
