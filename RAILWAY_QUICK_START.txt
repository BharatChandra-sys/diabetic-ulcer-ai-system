║                           TROUBLESHOOTING                                    ║
╚══════════════════════════════════════════════════════════════════════════════╝

❌ Build Failed
   → Check logs in "Deployments" tab
   → Verify Dockerfile is in repo root

❌ 502 Bad Gateway
   → Check PORT=8000 is set
   → Wait for build to complete

❌ Database Connection Failed
   → Add DATABASE_URL reference to PostgreSQL

❌ CORS Error
   → Update ALLOWED_ORIGINS with your Vercel URL

❌ Firebase Auth Failed
   → Check SERVICE_ACCOUNT_JSON is single line
   → No newlines or extra spaces
