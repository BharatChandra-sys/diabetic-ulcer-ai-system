┌──────────────────────────────────────────────────────────────────────────────┐
│ 1. FIREBASE AUTHENTICATION (Required)                                        │
└──────────────────────────────────────────────────────────────────────────────┘

  Key: FIREBASE_PROJECT_ID
  Value: your-firebase-project-id
  
  Key: FIREBASE_SERVICE_ACCOUNT_JSON
  Value: {"type":"service_account","project_id":"...","private_key":"..."}
         ⚠️ Must be SINGLE LINE (no newlines!)

  📍 How to get:
     1. Go to https://console.firebase.google.com
     2. Select your project
     3. Project Settings → Service Accounts
     4. Click "Generate New Private Key"
     5. Convert JSON to single line:
        python -c "import json; print(json.dumps(json.load(open('key.json'))))"


┌──────────────────────────────────────────────────────────────────────────────┐
│ 2. FRONTEND URL & CORS (Required)                                            │
└──────────────────────────────────────────────────────────────────────────────┘

  Key: FRONTEND_URL

  Key: ALLOWED_ORIGINS
  Value: https://your-app.vercel.app,http://localhost:5173
         (Your Vercel URL + localhost for testing)

╔══════════════════════════════════════════════════════════════════════════════╗
║                            DEPLOYMENT STEPS                                  ║
╚══════════════════════════════════════════════════════════════════════════════╝

Step 1: Push to GitHub
  $ git add .
  $ git commit -m "Deploy to Render"
  $ git push origin main

Step 2: Create Render Blueprint
  1. Go to https://dashboard.render.com
  2. Click "New +" → "Blueprint"
  3. Connect your GitHub repo
  4. Click "Apply"
  
  ✅ Render will automatically create:
     - PostgreSQL database (medvision-db)
     - Backend service (medvision-ai-backend)

Step 3: Add Environment Variables
  1. Click on backend service: "medvision-ai-backend"
  2. Go to "Environment" tab
  3. Update these variables:
     - FIREBASE_PROJECT_ID
     - FIREBASE_SERVICE_ACCOUNT_JSON
     - FRONTEND_URL
     - ALLOWED_ORIGINS
  4. Click "Save Changes"

Step 4: Wait for Build (8-12 minutes)
  Watch logs for:
  ✓ Build succeeded
  ✓ Health check passed
  ✓ Your service is live at https://medvision-ai-backend.onrender.com

Step 5: Verify
  Open: https://medvision-ai-backend.onrender.com/health
  Should return: {"status":"healthy","environment":"production"}

Render free tier sleeps after 15 min → 30s cold start

Solution: UptimeRobot (Free)

  2. Create account
  3. Add monitor:

     - Interval: 5 minutes
  4. Save

Now your backend stays warm! ✅


╔══════════════════════════════════════════════════════════════════════════════╗
║                            TROUBLESHOOTING                                   ║
╚══════════════════════════════════════════════════════════════════════════════╝

❌ Health check failing?
   → Check logs for startup errors
   → Verify DATABASE_URL is set
   → Increase healthCheckTimeout in render.yaml

❌ CORS errors in frontend?
   → Update ALLOWED_ORIGINS with your Vercel URL
   → Remove trailing slashes
   → Redeploy backend

❌ Firebase auth failed?
   → Verify FIREBASE_PROJECT_ID matches console
   → Check SERVICE_ACCOUNT_JSON is single line
   → No newlines or extra spaces in JSON

❌ Database not connected?
   → Check DATABASE_URL is auto-linked
   → Verify PostgreSQL database is running
   → Check logs for connection errors
