□ Open: https://your-backend.onrender.com/docs
  Should show Swagger API documentation

□ Check Render logs for:
  ✓ "Database tables ready"
  ✓ "Running database migrations..."
  ✓ "firebase_uid column added" (or "already exists")
  ✓ "Database migrations completed successfully"
  ✓ "MedVision AI ready to serve requests"

□ Test Firebase auth from frontend:
  → Sign up with new account
  → Should redirect to dashboard
  → Check Render logs: "Firebase user authenticated: uid=..."


╔══════════════════════════════════════════════════════════════════════════════╗
║                         COMMON MISTAKES TO AVOID                             ║
╚══════════════════════════════════════════════════════════════════════════════╝

❌ Forgetting to update FRONTEND_URL
   → CORS errors in browser console
   
❌ Adding newlines in FIREBASE_SERVICE_ACCOUNT_JSON
   → "Invalid JSON" error on startup
   
❌ Using http:// instead of https:// for production URLs
   → Mixed content errors
   
❌ Adding trailing slash: https://app.vercel.app/
   → CORS mismatch
   
❌ Not clicking "Save Changes" after editing
   → Changes don't take effect
